ZF AXTrax 2 LF — Camera AR Viewer

This version uses the supplied AXTrax 2 LF visual directly in a mobile camera AR experience.

HOW TO TEST
1. Upload these files to the root of a GitHub Pages repository:
   - index.html
   - axtrax2lf-product.png
   - axtrax2lf-original.png
2. Open the GitHub Pages URL on your phone.
3. Tap Start camera AR.
4. Allow camera access.
5. Drag the product to position it.
6. Pinch or use +/- SIZE to resize.
7. Twist with two fingers or use ROTATE.
8. RESET restores the default view.

IMPORTANT
- HTTPS is required for mobile camera access.
- This is a high-clarity camera-overlay AR viewer, not a true 3D model.
- The supplied source is a single 2D render, so the viewer cannot reveal unseen side/rear geometry.
- For true walk-around 3D AR, provide an approved GLB/GLTF, FBX, OBJ, STEP, or other CAD/3D asset.
- Microphone is not requested.
- Camera video is not recorded or uploaded by this prototype.
