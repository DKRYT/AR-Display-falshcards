ZF TECHNOLOGY AR FLASHBOARDS — PROTOTYPE v3

FLOW
Desktop/laptop flashboard -> normal phone Camera app -> scan QR -> mobile browser -> allow camera -> point at AR anchor -> 3D technology appears.

TECHNOLOGIES
OnGuardMAX, ESCsmart, ABS / EBS, TraXon, OnLane Alert, Axles & Dampers.

HOW TO TEST PROPERLY
1. Host this entire folder on an HTTPS static host.
2. On the desktop/laptop, open flashboards.html.
3. Select a technology.
4. Open your phone's NORMAL Camera app.
5. Scan the QR shown on the flashboard.
6. Tap the link.
7. Allow camera access in the mobile browser.
8. Point the phone at the complete AR ANCHOR square on the flashboard.
9. Try HOW IT WORKS, TECH ON/OFF and EXPLODED VIEW.

IMPORTANT
Mobile camera/WebAR normally requires HTTPS. If flashboards.html is hosted on HTTPS, the QR links are generated automatically for the same folder. You can also use 'Set mobile URL' to enter the hosted HTTPS base URL manually.

PROTOTYPE LIMITS
- 3D geometry is conceptual and not official ZF CAD.
- The branded AR anchor is intentionally used for reliable first-stage tracking.
- Production upgrade: approved ZF GLB/CAD, richer technology animations, whole-board image tracking if desired, locally bundled libraries, analytics only if explicitly approved, and event/offline hardening.
